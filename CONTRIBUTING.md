# Contributing

Bug reports are the most useful contribution. Open an issue with:

- what you ran or what the hook said,
- what you expected,
- your Python version and OS.

For a false block or a wrong number, paste the sentence or the line of output. Don't paste whole transcripts; they contain your code and prompts.

Pull requests are welcome for fixes with a test. Keep it standard-library only and Python 3.9 compatible. Run `python3 -m unittest discover tests` before you push.
